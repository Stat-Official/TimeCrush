# 직주근접 지도 타당성

LH 단지 CSV 메타데이터와 Kakao 주소·대중교통 API 명세를 확인했다. 지도는 설계까지 다뤘다. 실제 조회에는 REST API 키와 서버 측 호출 구성이 필요하며, 모집 여부·공급 자격을 제공하려면 별도 공고 데이터가 필요하다.

| 자료 | 필드와 활용 | 확인 상태 |
|---|---|---|
| LH 전국 아파트 단지 | 단지코드·단지명·임대유형·주택유형·주소·세대수·지역본부. 오래된 단지는 주소 누락 가능 | 공식 11열 메타데이터 |
| LH 모집공고 | 공고 ID·공급 단지·모집상태·대상 계층·신청기간·자격 | 단지 현황과 별도 |
| Kakao 주소 변환 | 주소, 행정구역, 도로명·건물·우편번호, x 경도·y 위도 | 공식 명세 |
| Kakao 대중교통 | start_x, start_y, end_x, end_y. 경로의 totalTime(초), 거리(m), 환승, 요금과 단계 | /v2/routing/publictraffic 명세. 실호출 키 필요 |

구현 시 단지코드로 중복을 제거하고 좌표화 실패를 표시한다. 모집 상태는 최신 공고와 연결한다. 사용자 주소·직장 주소는 동의한 조회에서만 처리하고 서버에 장기 저장하지 않는 흐름을 설계한다. 가까운 후보를 추린 뒤 같은 시점에 현재 집과 후보 단지에서 직장까지 예상 편도 소요시간을 비교한다. 30분 이내·30~45분·45~60분으로 나누고 초를 분으로 환산한다. API 실패와 공고 미확인은 상태로 표시한다.
