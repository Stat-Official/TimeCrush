**🕰️ 2024 생활시간조사로 청년의 하루를 재량시간 중심으로 진단하고, 비교·재배분·정책 탐색까지 연결합니다.**

TimeCrush는 **2024 생활시간조사 MDIS 공공용 시간량 자료**를 활용하여 만 19–34세 청년의 평일 시간사용을 분석하는 연구 프로토타입입니다.

이용자가 하루의 수면·식사 및 개인관리·근로·통근·학습·구직·가사·돌봄 시간을 입력하면 남은 시간을 재량시간으로 계산하고, 시간빈곤·수면 부족·과로 신호를 확인할 수 있습니다. 또한 비슷한 청년 집단의 가중 평균·중앙값과 비교하고, 시간 재배분을 탐색한 뒤 시간사용 유형과 관련 정책·지원·안내를 확인할 수 있습니다.

## 🔍 분석 방법

1. **원자료 감사 및 분석대상 선정:** 2024 생활시간조사 시간량 자료의 실제 열·응답 분기를 점검하고, 만 19–34세이면서 월요일~금요일에 해당하는 일지를 선별합니다. 주행동 합계가 1,440분이 아닌 일지는 분석에서 제외합니다.

2. **행동시간 분류:** 실제 주행동 116개를 수면, 식사·개인관리, 근로, 통근, 학습, 구직·창업, 가사, 돌봄 및 기타 재량 활동으로 분류합니다. 동시행동 시간은 하루 총합 산출에 사용하지 않습니다.

3. **재량시간 계산:** 하루 1,440분에서 수면·개인관리와 근로·통근·학습·구직·가사·돌봄을 차감하여 재량시간을 산출합니다.

4. **시간빈곤 기준 산출:** 재량시간의 가중 중앙값을 계산하고 중앙값의 50%·60%·70% 미만을 각각 민감도 분석합니다. 기본 분석 기준은 **가중 중앙값의 60% 미만**입니다.

5. **개인조건 분석:** 당일 행동시간을 설명변수에서 제외하고 연령·성별·혼인상태·미취학 자녀·수도권·취업 여부 등을 이용한 가중 로지스틱 모형을 적합합니다. 취업자 모형에는 주업·부업 합계 근로시간과 종사상지위도 포함합니다.

6. **가중 분위회귀:** 재량시간의 0.10·0.25·0.50·0.75 조건부 분위에서 개인조건과의 관련성을 분석하고, 개인 단위 재표집으로 구간을 계산합니다.

7. **시간구성 및 재배분 분석:** 하루 1,440분이라는 구성자료 특성을 고려하여 ilr 기반 CoDA 분석을 수행합니다. 0분 처리 가정을 구분하고 10·20·30·45·60분의 시간 재배분 시나리오를 비교합니다.

8. **시간사용 유형 분석:** 시간빈곤 일지에서 근로·통근·학습구직·가사·돌봄·수면 6개 시간을 이용하여 표준화 원시간 및 ilr 군집을 비교합니다. 웹앱에는 표준화 원시간의 K=3 유형을 적용합니다.

9. **재현 및 교차검증:** KOSIS 및 국가데이터처 공표값과 행동시간·주관적 응답을 대조하고, 분석 결과와 앱에 내장된 기준·정책 데이터가 일치하는지 `validate.py`로 확인합니다.

## 🏆 주요 분석 및 구현 결과

### 재량시간과 시간빈곤 기준

원자료 **50,194행·304열**에서 만 19–34세 청년의 평일 일지 **4,920건, 3,255명**을 분석했습니다.

- 재량시간 가중 평균: **265.94분**
- 재량시간 가중 중앙값: **230분**
- 기본 기준선: 중앙값의 60%인 **138분**
- 138분 미만 가중 비율: **22.51%**
- 개인 단위 재표집 95% 구간: **21.08%~24.54%**

기준선 민감도는 다음과 같습니다.

| 중앙값 비율 | 기준선 | 가중 시간빈곤율 |
| ---: | ---: | ---: |
| 50% | 115분 | 17.28% |
| 60% | 138분 | 22.51% |
| 70% | 161분 | 30.75% |

### 개인조건과 시간빈곤

당일 행동시간을 제외한 가중 로지스틱 모형에서 프로젝트 결과표에 기록된 주요 결과는 다음과 같습니다.

| 조건 | 오즈비 | p |
| --- | ---: | ---: |
| 만 나이 5세 증가 | 1.13 | 0.044 |
| 여성 | 1.48 | <0.001 |
| 미취학 자녀 있음 | 2.49 | <0.001 |
| 수도권 | 1.27 | 0.010 |
| 취업 | 2.17 | <0.001 |
| 취업자 주업·부업 합계 10시간 증가 | 1.26 | <0.001 |

개인 분리 5겹 교차검증 AUC는 **0.638**, 가중 Brier 점수는 **0.166**입니다.

### 시간 재배분

구성자료 분석에서는 재량시간과 수면·식사 및 개인관리·근로·통근·학습구직·가사돌봄을 함께 다룹니다.

양수 활동 조합이 유지되는 일지에서 특정 활동의 10·20·30·45·60분을 재량시간으로 옮기는 시나리오를 분석합니다.

예를 들어 근로시간 30분을 재량시간으로 옮기는 모형 결과에서는 다음과 같은 평균 예측 변화가 기록되어 있습니다.

| 응답 | 변화 |
| --- | ---: |
| 항상 시간부족 | -2.39%p |
| 매우 피곤 | -2.72%p |
| 여가 불만족 | -1.64%p |
| 삶 불만족 | -0.77%p |

### 시간사용 유형

시간빈곤 일지 **1,095건**을 대상으로 시간사용 유형을 분석했습니다.

웹앱에 적용된 표준화 원시간 K=3 모형은 다음 세 유형으로 구성됩니다.

| 유형 | 일지 | 가중 비중 | 대표적 시간 특성 |
| --- | ---: | ---: | --- |
| 학습·구직 시간 집중형 | 197 | 18.55% | 학습·구직시간이 상대적으로 긴 유형 |
| 근로 시간 집중형 | 817 | 74.93% | 근로·통근시간이 상대적으로 긴 유형 |
| 돌봄 시간 집중형 | 81 | 6.52% | 가사·돌봄시간이 상대적으로 긴 유형 |

표준화 원시간 K=3의 실루엣은 **0.473**, 개인 재표집 중앙 ARI는 **0.986**입니다.

### 공식 공표값 교차검산

2024년 전국 10세 이상 전체 요일·성별 공표조건에서 주행동 시간을 재현하여 8개 지표를 국가데이터처 공표값과 대조했습니다.

8개 지표의 최대 절대 차이는 **0.366분**으로 기록되어 있습니다.

## ✨ 주요 기능

- **하루 시간 입력:** 수면, 식사·개인관리, 근로, 통근, 학습, 구직·창업, 가사, 돌봄 시간을 시·분 단위로 입력
- **재량시간 자동 계산:** 입력된 필수·의무시간을 1,440분에서 차감하여 남은 시간을 자동 계산
- **입력 합계 확인:** 입력시간이 하루 1,440분을 초과하면 진단 진행을 차단
- **시간 신호 확인:** 재량시간 138분 미만, 수면 420분 미만, 주당 근로시간 52시간 초과 여부 확인
- **유사 청년 비교:** 연령대·경제활동상태·미취학 자녀 여부를 활용하여 분석표본 내 유사집단의 가중 중앙값과 평균을 비교
- **시간 바꿔보기:** 현재 입력값을 기준으로 활동시간을 줄이거나 늘리며 재량시간과 재배분
- **CoDA 결과 확인:** 분석에 존재하는 10·20·30·45·60분 재배분 시나리오의 모형 결과 표시
- **시간사용 유형:** 근로·통근·학습구직·가사·돌봄·수면의 표준화된 시간구성을 K=3 군집 중심과 비교
- **시간 신호 유형:** 복합형·과로형·수면 부족형·자유시간 빈곤형·신호 없음의 조사 일지 가중 비율 표시
- **정책·지원·안내 탐색:** `study`, `work`, `commute`, `care`, `sleep` 카테고리의 관련 정보를 사용자 조건과 시간사용 특성에 따라 정렬
- **기록 저장:** 이용자 동의 시 브라우저 Local Storage에 기록 저장
- **기록 관리:** 저장 기록 삭제 및 `my_time_diaries.json` 파일로 다운로드

## 🚀 이용 및 실행 방법

TimeCrush는 분석 결과가 이미 삽입된 `app/index.html`을 통해 웹앱을 바로 확인할 수 있습니다.

### 1. 저장소 내려받기

```bash
git clone https://github.com/Stat-Official/TimeCrush.git
cd TimeCrush
```

GitHub ZIP으로 내려받은 경우 압축을 푼 프로젝트 폴더에서 실행합니다.

### 2. 웹앱만 확인하기

`app/index.html`을 브라우저에서 직접 열 수 있습니다.

브라우저가 `file://` 환경의 저장 기능 등을 제한하는 경우 프로젝트 루트에서 로컬 HTTP 서버를 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8000/app/
```

웹앱의 **입력 예시 채우기**를 이용하면 01 입력부터 06 정책까지 전체 흐름을 확인할 수 있습니다. 입력 예시는 실제 조사 참여자의 일지가 아니라 웹 기능 확인을 위한 합성 입력입니다.

### 3. Python 환경 설치

전체 분석을 다시 실행하려면 **Python 3.11 이상**과 원본 MDIS CSV가 필요합니다.

```bash
python -m pip install -r requirements.txt
```

### 4. 원자료로 전체 분석 실행

원자료 CSV 경로를 지정하여 분석을 실행합니다.

```bash
python src/run.py "<2024 생활시간조사 시간량 원자료 CSV 경로>"
```

`run.py`는 전처리와 주요 분석을 실행하고 `data/processed/youth_weekdays.csv`, 결과표, 모형 요약 등을 생성합니다.

기본 실행에서는 가중 분위회귀도 이어서 수행합니다. 분위회귀를 제외하려면 다음 옵션을 사용할 수 있습니다.

```bash
python src/run.py "<원자료 CSV 경로>" --skip-quantile
```

### 5. 웹앱 다시 생성

분석 결과와 정책 DB를 웹앱에 반영합니다.

```bash
python src/build_app.py
```

`build_app.py`는 `app/template.html`의 `__PAYLOAD__` 위치에 분석 결과·군집·CoDA·정책 데이터를 삽입하여 `app/index.html`을 생성합니다.

따라서 HTML·CSS·JavaScript 로직을 수정할 때는 `app/template.html`을 원본으로 수정하고 `build_app.py`를 다시 실행하는 방식을 사용합니다.

### 6. 보고서 및 검증 실행

```bash
python src/report.py
python src/validate.py
```

`validate.py`에서는 다음 항목을 확인합니다.

- 청년 연령·평일 조건
- 일지·개인 수
- 하루 행동시간 합계 1,440분
- 재량시간 구성식
- 시간빈곤 가중 비율과 기준선
- 로지스틱 결과 재현
- 가중 분위회귀 결과
- CoDA 합계 보존 및 시나리오 범위
- 표준화·ilr 군집 K=2–8 결과
- 국가데이터처 공표값 교차검산
- 웹앱 기준선·프로필·유사집단 통계
- SQLite 정책 수와 웹앱 내 정책 수 일치

검증이 성공하면 다음 메시지가 출력됩니다.

```text
Analysis and application data validations passed
```
